# NOVAPATH ADVISORY LTD website

A static, responsive website prepared for GitHub Pages.

## Before publishing

1. Open `index.html` and `privacy.html`.
2. Replace `contact@novapathadvisory.co.uk` with the confirmed business email address if different.
3. Review the privacy notice and amend it if you add analytics, a contact-form provider, newsletters or other third-party tools.

## Publish through GitHub Pages

1. Create or open your GitHub repository.
2. Upload all files and folders in this package to the repository root.
3. Commit the changes.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.
7. GitHub will provide the public website address after deployment.

## Files

- `index.html` — main one-page website
- `privacy.html` — privacy notice
- `assets/style.css` — design and responsive layout
- `assets/main.js` — navigation, year and subtle reveal effects

No build tools or paid hosting are required.
